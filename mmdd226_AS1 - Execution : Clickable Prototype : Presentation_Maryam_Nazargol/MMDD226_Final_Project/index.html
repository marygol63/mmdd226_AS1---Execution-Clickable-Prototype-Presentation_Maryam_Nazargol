Common User Task (Tested Across All Four Prototypes)

Scenario: Maryam Nazargol received an online delivery (Order #1234). A fragile item arrived broken/damaged in transit. Maryam wants to reach a live customer support specialist to request a replacement without being trapped in circular chatbot loops, without losing her place in line, and with her order details permanently visible.

Flow A

Order-First Support

"straight from order to agent (less steps)"

Surfaces "My Orders" right on the main menu. User taps Order #1234, clicks "Get help", selects "Damaged item", and connects directly to agent in 2-4 minutes.

Flow B

Support-First Navigation

"good if they don't have an order in mind"

Surfaces "Search help..." and Help Centre at the top. Guided progressive triage ("What do you need help with? An order") before choosing recent orders.

Flow C

Queue Transparency

"let them check order without losing their spot"

Realistic wait ranges (#12 → #5), dynamic progress bar, non-blocking order inspection tabs, and radiant alert ("An agent is ready for you!").

Flow D

Context-Aware Chat

"order details stay visible while chatting"

Slide-over Order Details tray for Portable Blender ($24.99), in-chat damaged photo upload, sticky input bar, and instant replacement agreement.

Design Solutions & Usability Issue Coverage Matrix

How each prototype systematically targets the five key usability issues identified in Walmart Canada's customer support UX research:

Identified Usability Issue Prototype A (Order-First) Prototype B (Support-First) Prototype C (Queue UX) Prototype D (Context Chat)
#1. Buried Support Links
Support hidden in deep Help Centre articles		 Surfaced directly on recent order delivery cards Primary Target: Prominent search bar & Help Centre menu Accessible from order claim dashboard Dedicated direct chat interface
#2. Excessive Navigation Steps
Too many screens before reaching live agent		 Primary Target: Reduced to 3 steps with pre-filled order Guided 3-step decision tree 1-click queue entry Direct conversation entry
#3. Misleading 00:00 Countdown
Countdown freezes at 00:00 causing anxiety		 Standard queue indicator Departmental wait estimate Primary Target: Honest ranges (2–5m) & dynamic position #12→#5 Active specialist presence dot
#4. Unresponsive Mobile Chat
Input field & Send button obscured on phones		 Clean mobile input Clean mobile input Optimized chat layout Primary Target: Fixed flex layout with guaranteed sticky input
#5. Loss of Order Context
User must repeat order # & item to live agent		 Order dossier pre-transferred Selected order attached to ticket Non-blocking tab preserves order info during queue Primary Target: Slide-out Order Dossier tray without chat reset
